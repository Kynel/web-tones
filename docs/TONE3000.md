# TONE3000 연동

[TONE3000](https://www.tone3000.com)은 NAM 캡처와 IR을 공유하는 커뮤니티 카탈로그입니다. Web Tones는 TONE3000 API로 앱 안에서 톤을 고르고 바로 체인에 불러옵니다. 백엔드 없이 브라우저만으로 동작합니다.

## 사용 방법

1. **NAM Capture** 또는 **Cabinet IR** 블록을 선택하고 **TONE3000에서 찾기**를 누릅니다.
2. **TONE3000 전체 카탈로그에서 고르기** → 새 창에서 TONE3000에 로그인하고 톤을 검색·미리듣기한 뒤 선택합니다.
3. 창이 닫히고 선택한 톤의 모델 목록(게인 세팅별 캡처 등)이 나타납니다. 하나를 고르면 내려받아 블록에 적용됩니다.
4. 한 번 로그인하면 **인기 / 최신 / 내 즐겨찾기 / 내 다운로드** 목록에서도 바로 고를 수 있습니다.

내려받은 파일은 `TONE3000 · @제작자` 태그와 원본 톤 링크(↗)와 함께 이 브라우저의 IndexedDB에 저장되어, 다시 받지 않고 재사용됩니다.

## 설정: publishable key

연동에는 TONE3000 **publishable key**(`t3k_pub_…`)가 필요합니다. 이 키는 OAuth `client_id`로, 브라우저 코드에 포함해도 안전합니다. **secret key(`t3k_cs_…`)는 절대 넣지 마세요.**

1. [tone3000.com/api](https://www.tone3000.com/api)에서 키를 발급합니다.
2. 키의 **Redirect URI**에 앱 주소를 정확히 등록합니다(끝의 `/` 포함).
   - 배포: `https://web-tones.vercel.app/`
   - 로컬 개발: `http://localhost:5173/` (loopback 주소는 등록 없이도 허용됩니다)
3. 키를 앱에 넣습니다. 둘 중 하나:
   - **빌드에 포함** — 환경변수 `VITE_T3K_PUBLISHABLE_KEY` (로컬은 `.env.local`, Vercel은 Project → Settings → Environment Variables). 모든 방문자가 설정 없이 사용합니다.
   - **브라우저에 직접 입력** — 환경변수가 없으면 다이얼로그가 키 입력란을 보여주고 `localStorage`에 저장합니다. 포크/셀프호스팅용.

## 동작 방식

```
[TONE3000에서 찾기] ── 팝업 ──▶ tone3000.com/api/v1/oauth/authorize
                                 ?prompt=select_tone&format=nam&architecture=2 … (PKCE S256)
        ◀── redirect_uri?code=…&state=…&tone_id=… ── (팝업이 opener에 전달 후 닫힘)
POST /oauth/token (code + code_verifier)      → access/refresh 토큰
GET  /tones/{id}                              → 톤 정보(제목, 제작자, 라이선스)
GET  /models?tone_id=…[&architecture=2]       → 모델 목록
GET  model_url  (Authorization: Bearer …)     → .nam / .wav → IndexedDB → 블록에 적용
```

- **OAuth 2.0 Authorization Code + PKCE**. `state`를 가장 먼저 검증하고, PKCE 비밀값은 한 번 쓰고 지웁니다.
- **팝업 우선, 리디렉트 폴백** — 팝업이면 오디오가 끊기지 않습니다. 팝업이 차단되면 페이지 전체를 리디렉트하고, 돌아왔을 때 작업 중이던 체인(`localStorage`)과 요청한 블록을 복원합니다.
- **토큰**은 `sessionStorage`에만 둡니다(탭을 닫으면 사라짐). 만료 60초 전에 자동 갱신하고, 401이면 한 번 갱신 후 재시도합니다. 토큰은 `www.tone3000.com` 이외의 주소로는 보내지 않습니다.
- NAM 톤의 모델 목록은 A2와 A1/Custom을 각각 조회해 합칩니다(TONE3000은 `architecture`를 지정하지 않으면 A2 전용 모델을 빼고 응답합니다).
- 블록이 불러올 수 있는 형식만 보여줍니다: NAM 블록 → `format=nam`, Cabinet IR 블록 → `format=ir`.

코드: `src/t3k/oauth.ts`(순수 함수: PKCE, URL, 콜백 검증), `src/t3k/client.ts`(토큰, API, 팝업/리디렉트 플로우), `src/ui/T3kDialog.tsx`(UI).

## API 이용 조건 (TONE3000 정책)

TONE3000 문서 기준으로, 비상업(오픈소스·DIY) 무료 등급은 **OAuth 선택 플로우**(`select_tone`, `load_tone`)와 **제한된 목록 엔드포인트**(favorited, downloaded, created, trending, latest)만 쓸 수 있습니다. 그래서 이 앱은 자체 검색 UI를 만들지 않고, 검색은 TONE3000의 선택 화면에 맡깁니다.

- `/tones/search`는 무료 등급 대상이 아니며 강한 rate limit이 걸려 있어 사용하지 않습니다.
- 기본 rate limit은 분당 100회입니다. 429 응답은 사용자에게 안내합니다.
- **상업적으로 쓰려면** TONE3000과 별도 계약 및 출시 전 검토가 필요합니다.
- 표기 요건: 톤마다 제작자 이름·아바타, 장비 종류·형식을 표시하고 TONE3000 브랜드와 전체 카탈로그로 가는 경로를 유지해야 합니다. 현재는 워드마크 텍스트로 표기하고 있으며, **공개 출시 전에 공식 로고 키트로 교체**해야 합니다([API 문서](https://www.tone3000.com/api)와 [API 약관](https://www.tone3000.com/api/terms) 확인).

## 테스트

- `npm test` — PKCE(RFC 7636 벡터), authorize URL, 콜백 검증
- `npm run smoke` — TONE3000 API를 문서의 응답 형식대로 모의(mock)해 키 입력 → 팝업 선택 → 토큰 교환 → 모델 다운로드 → NAM 엔진 로드, 그리고 팝업 차단 시 리디렉트 폴백까지 검증합니다.

실제 TONE3000 서버와의 왕복은 발급된 키가 있어야 확인할 수 있습니다.
