## 알려진 제약

- 지연 시간은 브라우저와 OS 오디오 스택에 좌우됩니다. Chrome + 오디오 인터페이스 조합이 가장 낮습니다.
- NAM 모델은 CPU를 많이 씁니다. 버벅이면 NAM 블록의 Quality를 Lite로 낮추세요. Lite는 A2(슬리머블) 모델에서만 동작하고, 기존(legacy) 모델은 항상 전체 크기로 실행됩니다.
- 사용자 파일이나 TONE3000에서 받은 파일을 쓴 블록은 공유 링크로 전달되지 않습니다(받는 쪽 브라우저에 파일이 없음).
- 페이저의 피드백 경로에는 Web Audio 제약상 한 렌더 블록(128 샘플)의 지연이 들어갑니다.
